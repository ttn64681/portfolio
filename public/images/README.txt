Rules for displaying projects/experience/games images for explore and extra pages:
1. Name of folder roughly corresponds with the matching project/experience/game name
2. 'hero_' at beginning of file name indicates to use that image for the hero section image as well as gallery. If no hero_ image is specified, just pick one that best fits.
3. .gif files have priority to be the ones displayed next to the figure sections (features, implementation, and challenges). If no gifs for a proj/exp/game entry, use any available image in no particular order.
